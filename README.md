# pairwise-suspension-tire

越野车驶上台阶时车身突然弹飞，悬挂射线只从硬点向下打，没考虑轮胎半径和台阶边缘的法线；固定步长物理在低帧率下追帧，悬挂力和阻尼用了可变 dt；轮胎摩擦圆按单点算，侧向力超过附着极限仍继续加速；质量转移只作用在簧上质量，转弯时内侧轮悬空却没卸载；网络预测在坡道上把重力当常量，客户端和服务端高度逐渐分离；倒车时轮速方向没取反，ABS 和牵引力控制反向介入；手刹只锁后轮转速，没把侧向摩擦一起降下来；斜坡上停车时悬挂持续微抖，休眠阈值只看线速度；碰撞响应把车身当成单个凸包，底盘擦到石头直接弹起；不同平台浮点精度差异让同一段坡道轨迹分叉。gameplay/vehicle_suspension.py 是核心，tests/test_vehicle_suspension.py 15个红。要修的是：悬挂射线带轮胎半径并取边缘法线；固定步长累积器；摩擦圆按载荷分配；质量转移含簧上簧下；重力按位置采样并同步；倒车轮速取反；手刹同时降侧向摩擦；休眠看角速度与加速度；底盘多接触点；确定性定点积分。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
